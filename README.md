# Hi there, I'm Francisco Martins

### Cybersecurity Intern | SIEM & Detection Engineering | SOC Operations

I'm a cybersecurity professional focused on **SOC operations, security monitoring, detection, and security event analysis**.

I enjoy working hands-on with security platforms such as **Wazuh, Suricata, TheHive, Cortex, MISP, Graylog, and Zabbix**, using lab environments to deploy, test, troubleshoot, and better understand how these solutions work together.

My current focus is **SIEM and Detection Engineering**, particularly around log analysis, alert investigation, detection rules, false-positive analysis, tuning, and understanding which events actually matter instead of simply reacting to everything that generates an alert.

Most of my work is done in **Linux**, with experience across **Ubuntu, Debian, Kali Linux, Windows, and macOS**. I use virtualization and lab environments to test different architectures and scenarios, including **VMware and Proxmox**.

I also use **Python and Bash** to automate tasks, process security data, and build tools that make security workflows more efficient.

## Wazuh Distributed Lab

One of my main projects is a hands-on **Wazuh Multi-Node Distributed Architecture Lab**, where I built and documented a distributed Wazuh environment with separate components for the **Indexer, Server, and Dashboard**.

The project focuses on understanding how a real-world SIEM deployment can be structured rather than simply running everything on a single machine.

[View the Wazuh Distributed Lab →](https://github.com/fmartinscybersec/wazuh-distributed-lab)

## A Little About Me

I'm generally a relaxed person. I like to keep things simple, have a laugh, learn by doing, and I'm not afraid of breaking something in a lab while trying to understand how it works.

When it comes to work, though, I'm serious about getting things right.

I like troubleshooting, digging through logs, asking *"why did this happen?"* and staying with a problem until I understand what's actually going on.

I don't pretend to know everything. Cybersecurity is too big for that.

What I do enjoy is learning, experimenting, documenting what I find, and getting better with every problem I solve.

And if everything is on fire, I probably won't panic.

I'll just start looking at the logs to figure out **why**.
